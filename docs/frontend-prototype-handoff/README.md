# RAILNOVA — Frontend Prototype Pack

This folder preserves the separately supplied frontend-first prototype brief and its handoff notes. It is a design/prototype reference pack, not a replacement for the existing Next.js application at the repository root.

## Included
- `prompts/MASTER_WEBSITE_GENERATION_PROMPT.md` — full Stage 1 product and UX brief.
- `prompts/FRONTEND_ONLY_BUILD_PROMPT.md` — concise frontend build brief.
- `design/design-tokens.json` — prototype visual tokens.
- `docs/IRCTC_WORKFLOW_RESEARCH.md` — workflow research snapshot.
- `docs/FRONTEND_SCOPE_AND_ACCEPTANCE.md` — prototype scope and manual checks.
- `docs/DATABASE_BACKEND_PHASE_2.md` — future backend plan.
- `docs/PAYMENT_GATEWAY_AND_TICKET_UI.md` — payment/ticket handoff.

## Important distinction
The current repository README describes the existing Next.js + Supabase application. The uploaded prototype README describes a frontend-only demonstration with local demo data and simulated payments. They are different project stages/architectures, so this pack is kept in a clearly named subfolder rather than overwriting the root README.

The prototype notes explicitly prohibit live railway booking, real payment collection, and production authentication until the appropriate authorised integrations and security work are completed.
