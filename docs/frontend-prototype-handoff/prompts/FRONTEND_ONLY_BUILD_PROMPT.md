# FRONTEND-ONLY BUILD PROMPT

Build the RAILNOVA frontend now. Read `MASTER_WEBSITE_GENERATION_PROMPT.md`, `docs/IRCTC_WORKFLOW_RESEARCH.md`, `docs/FRONTEND_SCOPE_AND_ACCEPTANCE.md` and `design/design-tokens.json` first.

Use only frontend technologies in this phase. Do not create database tables, connect Supabase, add API secrets, call railway endpoints or integrate real payments. Use the supplied six images. Build the booking funnel: home/search → results → passenger details → review → payment-method choice → simulated confirmation. Also build PNR, live status, timetable, chart/vacancy, My Trips, services, account and help pages.

The experience should have the familiar depth and decision structure of a serious Indian railway booking website, but an original RAILNOVA identity and visual system. It must be responsive, accessible, consistent, visually polished and useful. Clearly label all demo data, simulated payment, demo PNR and sample bookings.

At completion, run the manual acceptance checklist. Report any limitations honestly. Stop after frontend delivery and wait for approval before Phase 2.
